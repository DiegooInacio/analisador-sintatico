GRAMÁTICA
PROG → public class id { public static void id ( ) { CMDS } }
CMDS → CMD CMDS
CMDS → ε
CMD → DECL
CMD → ATRIB
CMD → IF_STMT
DECL → TIPO id ;
TIPO → int
TIPO → float
TIPO → char
ATRIB → id = E ;
IF_STMT → if ( COND ) { CMDS } SENAO
SENAO → else { CMDS }
SENAO → ε
COND → E OP_REL E
OP_REL → ==
OP_REL → !=
OP_REL → <
OP_REL → >
E → T E'
E' → + T E'
E' → - T E'
E' → ε
T → F T'
T' → * F T'
T' → / F T'
T' → ε
F → ( E )
F → id
F → num

CONJUNTOS FIRST E FOLLOW
Não-terminal | FIRST                           | FOLLOW                            
-------------+---------------------------------+-----------------------------------
PROG         | { public }                      | { $ }                             
CMDS         | { char, float, id, if, int, ε } | { } }                             
CMD          | { char, float, id, if, int }    | { char, float, id, if, int, } }   
DECL         | { char, float, int }            | { char, float, id, if, int, } }   
TIPO         | { char, float, int }            | { id }                            
ATRIB        | { id }                          | { char, float, id, if, int, } }   
IF_STMT      | { if }                          | { char, float, id, if, int, } }   
SENAO        | { else, ε }                     | { char, float, id, if, int, } }   
COND         | { (, id, num }                  | { ) }                             
OP_REL       | { !=, <, ==, > }                | { (, id, num }                    
E            | { (, id, num }                  | { !=, ), ;, <, ==, > }            
E'           | { +, -, ε }                     | { !=, ), ;, <, ==, > }            
T            | { (, id, num }                  | { !=, ), +, -, ;, <, ==, > }      
T'           | { *, /, ε }                     | { !=, ), +, -, ;, <, ==, > }      
F            | { (, id, num }                  | { !=, ), *, +, -, /, ;, <, ==, > }
